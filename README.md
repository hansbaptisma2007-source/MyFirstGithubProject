# MyFirstGithubProject Cutting Edge Technology Subject 2nd Year College

Learning Experiences: 
Learning GitHub has been a meaningful and educational experience because it helped me understand how developers manage, organize, and collaborate on projects. At first, I found it challenging to learn the different features and commands, such as creating repositories, uploading files, committing changes, and pushing updates. However, as I continued exploring GitHub, I gradually understood how it works and how useful it is for storing and managing code online. I also learned that GitHub allows multiple people to work together on the same project, track changes, and share their ideas. Through this experience, I developed new technical skills, improved my understanding of version control, and realized how important GitHub is in programming and software development. Overall, learning GitHub taught me to be more patient, responsible, and willing to explore new technologies.
